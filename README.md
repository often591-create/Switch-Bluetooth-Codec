# 蓝牙编码切换

一个免费的 Android 小工具，可以手动切换蓝牙耳机/音箱使用的编码（SBC、AAC、aptX、aptX HD、LDAC、LC3…），也能调整采样率、位深度和 LDAC 音质。

- 需要 Android 14 或以上，不用 root
- 只会显示手机和耳机**都支持**的编码
- 第一次切换时，系统会请你允许这个 app 管理这副耳机，按「允许」即可
- 下拉通知栏 → 编辑快捷开关，加入「蓝牙编码」，点一下就能轮流切换

## 下载

到右边的 **Releases**，下载最新版本里的 `BtCodecSwitch.apk`，在手机上打开安装（需要允许「安装未知应用」）。

每次修改程式码推送到 main，GitHub Actions 都会自动编译并发布新版本。
